¿Qué es el reporte gráfico?

A veces lo verás como dashboard. No es un menú: es una imagen con gráficas que resume lo que pasó en la sesión, hecha con matplotlib y guardada como .png.

Para el puntaje máximo: dos o más gráficas con títulos y ejes, y una que compare tu evaluación de fortaleza (F2) con el resultado de las filtraciones (F1).

La técnica

Cómo preguntar sin revelar tu contraseña

Have I Been Pwned guarda miles de millones de contraseñas filtradas. El truco, llamado K-Anonymity, es preguntarle si la tuya está ahí sin decirle cuál es. Pruébalo con una contraseña de la lista.

1

Elige una contraseña de prueba

2

Se convierte en un hash SHA-1

B1B3773A05C0ED0176787A4F1574FF0075F7521E

Un hash es como una huella: la misma contraseña siempre da la misma, y de la huella no se puede sacar la contraseña.

3

Se parte en dos

Viaja por internetB1B37api.pwnedpasswords.com/range/B1B37
Se queda en tu computadora73A05C0ED0176787A4F1574FF0075F7521E

Cientos de hashes empiezan con esos mismos 5 caracteres. El servidor no puede saber cuál es el tuyo: te escondes entre cientos.

4

El servidor responde con todos los que empiezan igual, y tu programa busca el tuyo

Código base

Los mismos 4 pasos, en Python

El notebook de Moodle hace esto, una celda por paso. Funciona una vez, con una contraseña y si todo sale bien. No es el proyecto: es el punto de partida de F1.

Paso 1 · Calcular el hash
[ ]
import hashlib

password = "qwerty"   # de la lista de prueba
hash_completo = hashlib.sha1(password.encode("utf-8")).hexdigest().upper()

.upper() pasa el hash a mayúsculas porque así responde la API, y "b1b37" == "B1B37" da False.

Paso 2 · Partir el hash
[ ]
prefijo = hash_completo[:5]
sufijo = hash_completo[5:]
Paso 3 · Preguntar a la API
[ ]
import requests

URL_API = "https://api.pwnedpasswords.com/range/"
ENCABEZADOS = {
    "User-Agent": "ProgramacionI-CUGDL-EvaluadorContrasenas",
    "Add-Padding": "true"
}
respuesta = requests.get(URL_API + prefijo, headers=ENCABEZADOS, timeout=10)
PartePara qué está
User-AgentLe dice a la API qué programa pregunta.
Add-PaddingAgrega líneas falsas con 0 para que el tamaño de la respuesta no revele nada.
timeout=10Si en 10 segundos no responde, Python deja de esperar y marca error.
Paso 4 · Buscar tu sufijo, en tu computadora
[ ]
veces = 0
for linea in respuesta.text.splitlines():
    sufijo_api, conteo = linea.split(":")
    if sufijo_api == sufijo:
        veces = int(conteo)
        break

API
Un servicio al que tu programa le hace preguntas por internet y que responde con datos.

getpass
